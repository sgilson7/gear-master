Gear Master · milestone C7

The Threshold Run

How to watch a run walk the Manse chain from a cold start — find a word at a bar, hear out an astronomer, open a gate that has no wall, and go down a staircase for a sense nobody upstairs has yet. One command if you just want to see it. Six if you want to make it yourself — and a straight answer, at the bottom, about which half of this is learned.

If you only run one thing

A finished run is already committed. It is a transcript of keys a person could have pressed, and the window replays it without a hand on the mouse. 

GEARMASTER_WATCH=analysis/proofs/AA8D95DE31880461-grinder-medium-pathfinder_threshold.proof \
  cargo run -p gearmaster-gui

A macroquad window opens on rung one and plays forward: shopping, packing, doors, fights. It leaves each result screen by itself after two and a half seconds. It ends at rung 26 wearing Threshold-Sighted, with the mind lane open. The policy walking it is written rather than trained — see Which half of this is learned below, which is the honest part of this page.

What makes it a proof

The transcript replays into a fresh console and reaches the same rung with zero refusals. Every key in it is one the interface offers — there is no skip_to and no force_win. All three halves are there: the road decisions, the shopping the chain asked for, and the packing. Only the presses that stuck, because four fifths of what the hands do is seat-and-undo.

The chain it is walking

Nobody typed this list. engine::quest::chain_to walks the event, town, dungeon and rumour tables backwards from the class at the end, and the windows are then tightened against each other. The tiers are what the agent is paid at.

Tier What has to have happened Rungs
Prerequisite Holding("A Word About the Wrong Stars") 8–25
Offered Offered("the-astronomer") 18–25
Chose Holding("A Word About the Cellar") 18–25
Offered Offered("the-locked-gate") 23–25
Chose Gate("THE MANSE") 26
Chose Entered("the-threshold") 26–50
Finish Wearing("Threshold-Sighted") 26–50
The deadline — rung 25

THE MANSE is hidden and stands after rung 25, and a town gate is offered on exactly one rung. So the word has to be in hand, and the gate opened, before rung 25 is cleared.

Past that there are four rungs — 26 to 29 — where the run is still offered both doors, still takes the right choice at both, and still puts the town on the map. The house is twenty-five rungs behind it. Three of the four tiers pay in full on a run that cannot finish, which is why the cheap tiers are potential-based and add to nothing.

Making it yourself

Six steps, in order. Everything runs from the repository root. Nothing needs a network, a key, or a service — the engine has no dependencies at all and the learning crates carry their own.

1

See the chain

Derived from the tables, so this is the first thing to check after any content change. It prints all three named chains and refuses the one that cannot be handed to an agent. 

cargo run -p gearmaster-lab --bin qquest

pathfinder_drover is refused on purpose: a county chain is a flag, and the screen shows no flags.

2

Check it is reachable at all

Before spending an hour training, ask whether a run that follows the plan perfectly can finish. QAIM_ROAD=written is handed the chain and told which choice passes which stop — an upper bound, not a baseline. 

QAIM_ROAD=written QAIM_RUNS=24 \
  cargo run --release -p gearmaster-lab --bin qaim
Holding("A Word About the Wrong Stars")   8-25    7/24
Offered("the-astronomer")               18-25     2/24
...
Wearing("Threshold-Sighted")            26-50    1/24

The wall is the first stop, and it is about time rather than choice: seven runs in twenty-four are alive and at a bar before rung 25.

3

Train the pathfinder

Q-learning over the road, with packing as one macro-action into a frozen packer. The chain is in the reward and two of the road features are how far along it is. 

QROAD_QUEST=pathfinder_threshold QROAD_EPISODES=500 \
  cargo run --release -p gearmaster-lab --features nn --bin qroad

About five seconds an episode on an M2 Max, so 500 is roughly forty minutes. It writes runs/pathfinder_threshold.txt — plain weights, one line a tensor.

The packer defaults to the written control

And it has to. The learned packer assembles 2.8 items and clears 8 rungs of 50; the chain's first door stands at rung 18. Training against a packer that cannot get there makes every failure ambiguous between the two agents.

4

Measure what it learned

The same harness as step 2, with the trained weights in place of the plan. It prints which stop each seed reached, so a run worth watching can be found by its seed. 

QAIM_QUEST=pathfinder_threshold \
QAIM_NET=runs/pathfinder_threshold.txt \
  cargo run --release -p gearmaster-lab --bin qaim

Leave QAIM_NET off for the honest baseline: the first legal step every time, which knows nothing.

5

Write a proof

One seed, played and then replayed into a fresh console and compared. If the two disagree the file is not written as a proof of anything. 

QPROOF_QUEST=pathfinder_threshold \
QPROOF_ROAD=runs/pathfinder_threshold.txt \
QPROOF_SEED=0xAA8D95DE31880461 \
  cargo run --release -p gearmaster-lab --bin qproof
seed 0xAA8D95DE31880461: rung 26, 166 road decisions, 66 packs, 220 presses
stops passed: 7/7
replayed to rung 26 with 0 refusals  - identical

QPROOF_ROAD=written uses the plan-follower instead, which is how the committed proof was made.

6

Watch it

The proof's own header carries this line with its filename already filled in, so it can be copied straight out of the file. 

GEARMASTER_WATCH=analysis/proofs/<file>.proof \
  cargo run -p gearmaster-gui

The window opens at the board rather than the intro, plays every key in order, and holds each fight's result long enough to read before moving on.

Which half of this is learned

The run in the committed proof is walked by a written policy that was handed the chain. The trained networks exist, and they do not work. Both were given 500 episodes against the same packer:

Road policy Deepest rung Finished
No weights — first legal step10/24
pathfinder_threshold10/24
pathfinder_unwound10/24
Written, following the plan261/24

Neither model beats its own absence. Every figure above zero on this page belongs to the written half, and the reason is one measurement rather than a tuning problem.

The network sees one action where the console offers four

The move description was written for the packing agent. Its one-hot has eight shapes — place, buy, sell, barter, reroll, rotate, unequip, clear — and one bucket for everything else, and every field after it describes a piece, which no road verb has. 

1,341 road verbs offered across four runs
four kinds among them: answer, drink, fight, town
distinct feature vectors the network can see: 1

So the road network chooses between pack — the all-zero action by convention — and a road verb. Which road verb is the order the console listed them in. A network that cannot tell two actions apart cannot prefer one, and no amount of reward shaping teaches a preference between things that are the same input.

Reproduce it with cargo run --release -p gearmaster-lab --bin qmoves. The figure is pinned at 1 by a ratchet that is meant to go up: fixing it means describing a road verb the way a placement is described — which choice at which door, what it asks for, what it does — and all of that is already on the screen, so it costs the agent-engine boundary nothing.

If something looks wrong

The run loses rung one over and over

The packer was handed a budget of the wrong kind. Forty is a budget on decisions for the learned packer; the written control is exhaustive over anchors and needs a budget on presses — its median is 492. Given forty it buys pieces, seats none, and fights on what it was dealt.

The first stop is never reached

The word is bartered for, and Barter belongs to the quartermaster, so the pathfinder can never press it. The driver buys it programmatically from a list derived from the chain's own unpassed stops. If that is skipped, the first stop is unreachable by construction.

A checkpoint loads and behaves like noise

Road weights are stored at the width of a road pair, and that width moved from 51 to 53 when the chain progress columns landed. An older file loads and reads every column one place to the left.

cargo run says it built without the trainer

qroad needs --features nn. Everything else in the list runs without it, which is deliberate: the neural framework is off by default and never in CI.
